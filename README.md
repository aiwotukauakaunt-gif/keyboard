# Keyboard — ブラウザだけで動く音楽練習ツール

> **English:** Keyboard is a free, install-free set of practice tools for musicians (especially wind players) that runs entirely in your browser: a transposing keyboard with just intonation, a tuner with drone and long-tone tracking, an advanced metronome with shareable rhythms, a backing looper, a recorder, and a habit-friendly practice log. Switch the UI to English with the **EN** button. Your data never leaves your browser.

**▶ 使う：https://aiwotukauakaunt-gif.github.io/keyboard/**

鍵盤 · チューナー · メトロノーム · 伴奏ループ · 録音 · 本格録音 · 練習記録 がひとつになった、
インストール不要の練習ツールです。外部ライブラリなし。

## 使い方

- `index.html` をブラウザで開くだけで動きます。
- **チューナー・録音（マイク）** は `https://` または `localhost` で開いたときだけ使えます
  （`file://` で直接開くとブラウザの制限でマイクが使えません）。
  ローカルで試すなら：

  ```bash
  python -m http.server 8765
  ```

  → http://localhost:8765 を開く

- データ（設定・プリセット・伴奏ループ・練習記録・日記）はすべてそのブラウザの
  localStorage に保存されます。サーバーには何も送りません。

## 機能

| ツール | 内容 |
|---|---|
| 🎹 鍵盤 | A0〜C8、基準ピッチ 415〜466Hz、平均律/純正律（主音選択・純正律のときは各キーと「いま弾いた音」に平均律との差をセント表示）、移調（12種の管）、オクターブ、保持モード、PCキー演奏（JIS対応・↑↓←→で移動）、スペース＝サステイン、音色4種（標準／サイン波／オルガン／ブラス風）、鍵盤サイズ3段階、マルチタッチ、**MIDIキーボード入力**（Web MIDI・サステインペダル対応）、練習ハブ（いま弾いた音・基準ピッチ・純正律との差） |
| 🎯 チューナー | マイク入力、針メーター（±50¢）、♭/♯表示、純正律の長3度/短3度マーカー、**ドローン**（参照音を鳴らし続ける）、**ロングトーン練習**（保持秒数・範囲内秒数・安定度を自動計測、ピッチ推移グラフ、結果履歴） |
| 🥁 メトロノーム | **共有URL**（テンポ・拍子・リズムをURLにしてSNSで共有）、0.01〜100000 BPM（スライダーは15〜400）、TAP、BPM計算（÷2 ×2 ÷3 ×3 ÷n ×n）、拍子・分割、3状態リズムグリッド、プリセット7種、アクセントグルーピング（3+2+2）、音色5種、ギャップ練習、テンポトレーナー、音量（全体＋バランスプリセット）、カウントイン、ポリリズム（2声）、視覚のみ、設定の保存 |
| 🔁 伴奏ループ | 鍵盤演奏を拍単位で記録してテンポ追従ループ再生、録音時のリズムも再現、**重ね録り（オーバーダブ・複数トラック・ミュート）**、名前付き保存 |
| 🎙️ 録音 | マイク＋アプリ音ミックス、WebM / WAV 保存、**ブラウザ内（IndexedDB）に保存されリロードしても残る** |
| 🎚️ 本格録音 | 楽器のための録音機 Tonmeister（`record/`）。マイクの音をブラウザの加工なしにそのまま（生フレーム取得・True Peak・押す前の音・24bit / FLAC・BWF）。**鍵盤・メトロノーム・伴奏ループの音は別トラックに、標本の単位で揃えて録る**（マイクの録りには混ぜない）。録音はブラウザ内（OPFS）に残り、書き出せる。配色・言語はこちらに追従。計測中のメニュー項目がテイク名に付き、録った本数と長さが「記録」の今日に残る |
| 📊 記録 | **2段階目標**（最低ライン／目標）、**週◯日目標**と週連続、日連続（休息日は週1回まで予約可・「2日続けて休まない」メッセージ）、**今日のメニュー**（項目＋分数のチェックリスト、項目ごとに計測、毎日自動セット）、前回の「次の課題」を先頭に表示→1クリックでメニューへ、レベル（通算時間）、12週ヒートマップ、今週/先週比・最長連続・平均、実績バッジ15種、自作目標、**振り返り**（できたこと・次の課題・調子・メモ） |

## 音名の表記

すべて英語音名で統一：**C Db D Eb E F F# G Ab A Bb B**（オクターブは C4＝中央ド）。
黒鍵は管楽器で一般的な Db・Eb・Ab・Bb（フラット）と F#（シャープ）で表記します。

## ショートカット

| キー | 動作 |
|---|---|
| Enter | メトロノーム開始/停止 |
| Shift + Enter | タップテンポ |
| Shift + ↑ / ↓ | テンポ ±1 |
| Shift + ← / → | テンポ ±10 |
| Shift + R | 録音 開始/停止 |
| Space | サステイン（押している間） |
| ← / → | PC鍵盤を1オクターブ移動 |
| ↑ / ↓ | PC鍵盤を半音移動 |

## バックアップ

ヘッダーの「💾 バックアップ」から、設定・プリセット・伴奏ループ・練習記録・日記を
JSONファイルに書き出し／読み込みできます（録音ファイルは含みません）。
ブラウザを変えるとき・キャッシュを消す前に。

## PWA（ホーム画面に追加・オフライン）

https で公開すると、スマホ/PCの「ホーム画面に追加」「アプリとしてインストール」が使えます。
一度開けばオフラインでも動きます（`sw.js` がファイルをキャッシュ。ネットワーク優先なので更新はすぐ反映）。

## 公開時にやること

- `sw.js` の `CACHE` のバージョン文字列を更新のたびに上げる（古いキャッシュを確実に捨てるため）。tonmeister 側の `python web/tools/sync_keyboard.py` を走らせると、中身のハッシュで自動的に変わる。
- GitHub Pages / Netlify / Cloudflare Pages など、静的ホスティングにフォルダごと置けば動きます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面 |
| `style.css` | デザイン（ライト/ダーク対応、CSS変数で配色変更可） |
| `i18n.js` | 日本語 / 英語（辞書で表示文字列を置換。ブラウザ言語で自動判定、ヘッダーで切替） |
| `core.js` | 共通ヘルパー・テーマ・バックアップ・PWA登録・オーディオ基盤・トースト |
| `keyboard.js` | 鍵盤（加算合成・描画・PCキー・マルチタッチ・MIDI・練習ハブ） |
| `tuner.js` | ドローン・チューナー・ロングトーン練習 |
| `metronome.js` | メトロノーム（スケジューラ・グリッド・練習モード・プリセット・共有URL） |
| `looper.js` | 伴奏ループ（録音・再生・重ね録り・保存） |
| `recorder.js` | 録音（WebM / WAV、IndexedDB） |
| `log.js` | 練習記録・振り返り |
| `app.js` | ツール表示トグルと初期化 |
| `manifest.json` / `sw.js` | PWA（`sw.js` の資源一覧と CACHE 名は `record/` の同期スクリプトが書き換える） |
| `record/` | 本格録音（Tonmeister の Web 版）。本体は別リポジトリ [tonmeister](https://github.com/aiwotukauakaunt-gif/tonmeister) の `web/` で、`python web/tools/sync_keyboard.py` で写す。直接は編集しない |
| `icon-*.png` / `og-image.png` | アイコン・SNSシェア画像 |

モジュール間は `window.KB` を通じて連携します（読み込み順は `index.html` のとおり）。ビルド不要・外部ライブラリなし。
